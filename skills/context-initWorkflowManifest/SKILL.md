# context-initWorkflowManifest

Generate `workflow-manifest.json` in the active context folder. The manifest records the ordered stage names for every known SWC workflow so a fresh session can route to the correct stage without scanning skill files or relying on hardcoded mappings.

## Arguments

Receives the resolved context `absolute_path` (e.g. `/Users/.../project/.swc/feature_my-work`). Required — but if not provided as an argument, the skill resolves it via `context-lookup` rather than failing silently.

## Steps

### 0. Resolve write location

If `absolute_path` was passed as an argument, use it directly.

If no `absolute_path` argument was provided, invoke the `context-lookup` skill to locate the active context. Extract `absolute_path` from its output. If `context-lookup` fails or returns no path, stop and surface the error — do not proceed to write.

### 1. Produce the manifest JSON

Using your knowledge of the SWC workflows and their stages, construct the following JSON object:

```json
{
  "workflows": [
    {
      "name": "deliver",
      "stages": ["requirements", "specs", "solution-design", "implement", "refine", "review", "accept"]
    },
    {
      "name": "implement",
      "stages": ["orient", "implement", "summarise"]
    },
    {
      "name": "planning",
      "stages": ["context", "intent", "solution", "delivery", "breakdown", "finalise"]
    }
  ]
}
```

### 2. Write the manifest

Write the JSON object to `<absolute_path>/workflow-manifest.json` using the `Write` tool.

### 3. Return

Return silently — `context-init` handles confirmation.

## Exit criteria

**Done when** `workflow-manifest.json` exists at `<absolute_path>/workflow-manifest.json` and contains a `workflows` array with entries for `deliver`, `implement`, and `planning`, each with a `stages` array of stage name strings.

## Notes

- The manifest is a snapshot at init time. Workflow changes made after init are an accepted edge case — the manifest can be regenerated by re-running this skill.
- The manifest is written to the context folder, not to MCP meta.
- The JSON is produced from model knowledge, not by scanning skill files.
